# Mission: Build paid APIs and agent payment systems with Rust

## Why
Follow the user's x402 learning roadmap through runnable Rust projects. This first project builds the foundation: understanding how an HTTP payment challenge and retry work.

## Success looks like
- Run the API, demo client, and checks in Ubuntu containers.
- Trace an unpaid request through a 402 challenge and a successful simulated retry.
- Explain which parts must change before accepting real payments.

## Constraints
- Rust implementation; Ubuntu Linux Docker Compose execution.
- Tutorial 1 uses no wallets or actual funds.

## Out of scope
- Real signing and settlement belong to later roadmap projects.
