Commands and code map

docker compose up --build -d --wait api  # build and start API
docker compose run --build --rm demo    # run client in Ubuntu
docker compose run --build --rm checks  # format, tests, Clippy
docker compose exec api bash           # explore running Ubuntu
docker compose logs api                # view server output
docker compose down                    # stop project containers

Code map

Dockerfile: Ubuntu development tools → compiled release binary → Ubuntu runtime. compose.yaml: services and networking. main.rs: listener and shutdown. lib.rs: routes and demo payment checks. demo.sh: unpaid request, decode challenge, build payload, retry. tests/lifecycle.rs: rejection and success checks.

Vocabulary

Challenge: payment requirements advertised by the server. Authorization: payload submitted by the client; simulated here. Settlement: actual execution of payment; absent here. Base64: reversible encoding, without authentication or encryption.

PAYMENT-REQUIRED goes server → client; PAYMENT-SIGNATURE goes client → server. Header names are case-insensitive.

Inside the demo container, api is the API service hostname. Inside the API container, 127.0.0.1 refers to that container. On the host, port 3000 forwards to the API container.
